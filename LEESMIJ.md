# RIEfresh-website: overdracht aan Claude Code

Hoi Erik,

In deze map zit alles om riefresh.nl te laten bouwen:

- `CLAUDE.md`: de bouwopdracht. Claude Code leest dit bestand automatisch zodra je het in deze map start.
- `design/`: het goedgekeurde ontwerp als vier HTML-pagina's (home, KAM-managers, adviesbureaus, partners) plus de klantlogo's. Open `design/index.html` in je browser om het te bekijken.

Zo start je:

1. Pak de zip uit en open een terminal in de map `riefresh-website`.
2. Start `claude` en geef deze opdracht:

   > Lees CLAUDE.md en de bestanden in design/. Stel eerst een plan voor, en bouw daarna de website.

Wat er nog van jou nodig is:
- de link naar de publieke demo-interviewer (`[DEMOLINK]`);
- waar de demoformulieren heen moeten.

De privacyverklaring komt van Jorien, het logo van Coning en de bevestiging van de prijzen van mij.
